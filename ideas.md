## Abordagem 2 — Institucional Premium / Força e Tradição

<response>
<text>
**Design Movement:** Military Heritage / Institutional Premium
**Core Principles:**
- Fundo claro acinzentado com elementos escuros de autoridade
- Tipografia serif para títulos (tradição, confiança) + sans-serif para corpo
- Verde militar como cor dominante em seções alternadas
- Layout com margens generosas e hierarquia clara

**Color Philosophy:**
- Background: #F5F5F5 (cinza claro, limpo)
- Sections alternadas: #494F27 (verde escuro) e #FFFFFF

- Accent: #9EAB54
- Propósito: transmitir tradição desde 1996 + modernidade

- Seções full-width com alternância claro/escuro
- Hero com split: texto à esquerda, imagem à direita
- Cards de coleção em grid 3x2 com hover elevation
- Timeline horizontal para história da empresa

**Signature Elements:**
- Faixas horizontais em verde militar separando seções
- Ícones customizados estilo patch/emblema
- Bordas duplas finas em elementos de destaque

**Interaction Philosophy:**
- Hover suave com elevação (box-shadow)
- Transições de cor fluidas
- Mega menu com animação de deslizamento vertical

**Animation:**
- Scroll reveal com fade-in + scale de 0.97 para 1
- Header com blur backdrop ao rolar
- Cards com lift effect no hover

**Typography System:**
- Display: Playfair Display (autoridade, tradição)
- Body: Source Sans Pro (legibilidade)

## Abordagem 3 — Tático Moderno / Equipamento de Campo

<response>
<text>
**Design Movement:** Field-Ready Tactical / Modern Military Commerce
**Core Principles:**
- Fundo escuro profundo com gradientes sutis verde-escuro
- Tipografia bold e geométrica, sem serifa
- Elementos de UI inspirados em HUD / displays táticos
- Composição em camadas com profundidade visual

**Color Philosophy:**
- Background: #1E1E1E com gradiente para #2A2E18
- Primary: #5D6532
- Accent: #9EAB54 (verde lima vibrante para CTAs)
- Borders: #494F27 com opacidade
- Propósito: modernidade tática, confiança profissional

**Layout Paradigm:**
- Hero full-viewport com partícula/textura animada sutil
- Seções com fundo escuro e cards com glassmorphism leve
- Grid de coleções com imagens de fundo e overlay gradiente
- Sidebar fixa no desktop para navegação de coleções

**Signature Elements:**
- Linhas de "scanning" animadas sutis no hero
- Corner brackets em elementos de destaque (estilo mira)
- Numeração de seções estilo militar (01 / 02 / 03)

**Interaction Philosophy:**
- Cursor customizado (crosshair) em elementos clicáveis
- Hover com borda verde animada (draw effect)
- Botões com ripple effect em verde

**Animation:**
- Hero text com typewriter effect
- Seções com parallax leve no scroll
- Cards com flip reveal no hover

**Typography System:**
- Display: Oswald (bold, geométrico, impactante)
- Body: Nunito Sans (moderno, legível)
- Accent: Courier New para detalhes técnicos
</text>

## Escolha Final

**Abordagem Selecionada: Abordagem 3 — Tático Moderno / Equipamento de Campo**

Design escuro profundo com identidade tática moderna, tipografia bold (Oswald + Nunito Sans), elementos de HUD/display tático, glassmorphism nos cards, numeração de seções estilo militar e animações de scroll reveal com Framer Motion. As cores oficiais da marca (#5D6532, #9EAB54, #494F27) serão usadas como accent sobre fundo escuro #1E1E1E.
